# Direct Image Grading Documentation (DEPRECATED)

**NOTE: This functionality has been removed from the application.** This documentation is retained for historical reference only.

## Overview

This document previously provided an overview of the direct image grading functionality that allowed clinicians to grade images uploaded directly to the system (bypassing the ZIP archive workflow).

## Deprecation Notice

The direct image grading functionality was removed from the application as part of the transition to a dual grading system. All image grading now occurs through the dual grading workflow which provides better quality control and consistency in clinical assessments.

## Historical Information

For historical reference, the direct image grading functionality included:

- Routes for direct image grading views
- Database models for tracking direct image uploads
- User interface components for direct image grading
- Access control mechanisms for direct image grading

This functionality has been completely removed and replaced with the dual grading system.
