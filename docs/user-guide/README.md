## About This System

The Fundus Image Management System is a comprehensive platform designed for eye hospitals to manage retinal fundus images. This system helps medical professionals:

- Upload and organize retinal images from various sources
- Grade images for eye diseases like Diabetic Retinopathy, Glaucoma, and AMD
- Review and analyze grading results
- Generate curated datasets for research and training

## Who Should Use This Guide

This guide is intended for:
- **File Uploaders**: Staff responsible for adding images to the system
- **Optometrists**: Vision care specialists who can upload images and perform initial screenings
- **Residents**: Medical residents performing initial image grading
- **Ophthalmologists**: Resident2 members providing expert assessments
- **Data Managers**: Administrators overseeing the system

## System Features

### Image Management
- Upload individual images or batch ZIP archives
- Support for various camera systems and image formats
- Automatic image validation and organization
- Specialized support for Remedio-FOP camera system ZIP downloads
- Upload AI pre-graded images with existing assessments
- Import resident2 and resident grades for AI-processed images

### Data Verification & Privacy
- Extracted data verification from uploaded ZIP files
- Image anonymization to protect patient identity
- Ability to hide Personally Identifiable Information (PII) embedded in images
- Secure handling of sensitive medical data

### Grading Workflow
- Three-tier grading process (Resident → Resident2 → Arbitrator)
- Disease-specific grading for DR, Glaucoma, and AMD
- Quality control through multiple assessments

### Analytics & Reporting
- Comprehensive dashboards for tracking progress
- Detailed reports on grading results
- Tools for identifying discrepancies and trends

- Modern web browser (Chrome, Firefox, Safari, or Edge)
- Stable internet connection
- Appropriate user account and permissions

## Security & Privacy

This system is designed with medical data security in mind:
- All data is encrypted and stored securely
- Role-based access control ensures users only see appropriate data
- Audit trails track all system activities
- All access is logged for compliance purposes
