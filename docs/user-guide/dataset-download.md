# Dataset Download

This guide explains how recipients download curated datasets.

## Steps

1. Open the download link provided by the dataset creator.
2. Enter the exact dataset name and the OTP.
3. After verification, review dataset details (disease, image count, share time).
4. Click **Generate Export** if no export is ready.
5. Download files once the export completes.

## Notes

- Exports are available for 20 hours; you can regenerate if needed.
- If the link is invalid or expired, contact the dataset creator.
- OTPs are case-insensitive.
