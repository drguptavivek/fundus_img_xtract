# Notifications System

The Fundus Image Management System includes a comprehensive notification system to keep you informed about important events, tasks, and updates. This guide explains how to use and manage notifications effectively.

## Understanding Notifications

Notifications are messages sent to you about system events that require your attention or provide important information. They help you stay updated on:

- New grading assignments
- Completed tasks and reviews
- System announcements
- Messages from other users
- Upload status updates

## Accessing Notifications

### Notification Bell Icon

1. Look for the bell icon (🔔) in the top-right corner of the screen
2. A red dot indicates unread notifications
3. The number shows how many unread notifications you have
4. Click the bell to view a dropdown list of recent notifications

### Notifications Page

For a complete view of all notifications:
1. Click the bell icon and select "View All Notifications"
2. Or navigate through the main menu: "Notifications" → "My Notifications"
3. This page shows all your notifications with advanced filtering options

## Notification Types

### System Notifications
- **Announcements**: Important system updates and maintenance notices
- **Alerts**: Critical system issues or urgent information
- **Reminders**: Automated reminders about pending tasks

### Task Notifications
- **New Assignments**: New grading tasks assigned to you
- **Task Updates**: Changes to task status or priority
- **Completion Notices**: When tasks you're involved in are completed

### User Messages
- **Direct Messages**: Messages from other users in your lab units
- **Admin Messages**: Communications from system administrators
- **Peer Messages**: Notifications from colleagues

### Upload Notifications
- **Upload Status**: Updates on your image uploads
- **Processing Results**: Completion of batch processing
- **Error Notifications**: Issues with uploaded files

## Managing Notifications

### Viewing Notifications

1. **Unread First**: Unread notifications appear at the top in bold
2. **Timestamp**: Each notification shows when it was sent
3. **Sender**: See who sent the notification (system or user)
4. **Type Indicator**: Icons indicate the type of notification

### Marking as Read

**Individual Notifications**:
- Click the notification to open and view details
- Click "Mark as Read" button
- Or click the checkmark icon next to the notification

**All Notifications**:
- Click "Mark All as Read" button
- This marks all visible notifications as read
- Useful for clearing a large number of notifications

### Filtering Notifications

Use filters to find specific notifications:

**By Type**:
- All notifications
- System notifications only
- Task notifications only
- User messages only

**By Status**:
- All notifications
- Unread only
- Read only

**By Date**:
- Today
- This week
- This month
- Custom date range

## Sending Notifications

### Composing Messages

You can send notifications to other users:

1. Click "Compose" in the notifications menu
2. Choose recipient type:
   - **Administrators**: Send to all system admins
   - **Lab Peers**: Send to users in your lab units
3. Fill in the message details:
   - **Title**: Brief subject line (max 100 characters)
   - **Message**: Detailed content (max 1000 characters)
4. Click "Send Message"

### Message Guidelines

**Best Practices**:
- Use clear, descriptive titles
- Be concise but thorough in your message
- Include relevant context or reference numbers
- Follow professional communication standards

**What to Include**:
- Your name and role
- Reference to specific images or tasks (if applicable)
- Clear action required (if any)
- Contact information for follow-up

### Broadcast Messages (Administrators Only)

System administrators can send broadcast messages to all users:
1. Navigate to "Notifications" → "Broadcast"
2. Compose your message
3. Select notification type (info, warning, alert)
4. Send to all active users

## Notification Settings

### Email Notifications

Configure email notifications for important updates:
1. Go to your profile settings
2. Select "Notification Preferences"
3. Choose which notifications trigger emails:
   - Task assignments
   - System announcements
   - Direct messages
   - Upload completions

### In-App Notifications

Control how notifications appear in the application:
- **Sound alerts**: Enable/disable notification sounds
- **Desktop notifications**: Allow browser notifications
- **Auto-refresh**: Set frequency for checking new notifications

## Troubleshooting Notifications

### Not Receiving Notifications

**Check These Settings**:
1. Verify your notification preferences in profile settings
2. Ensure you're assigned to correct lab units
3. Check browser permissions for desktop notifications
4. Verify email settings for email notifications

**Common Solutions**:
- Refresh your browser
- Clear browser cache
- Check your spam folder for email notifications
- Verify your account is active

### Notification Display Issues

**Problems and Solutions**:
- **Notifications not loading**: Refresh the page or check internet connection
- **Old notifications showing**: Clear browser cache and refresh
- **Can't mark as read**: Try refreshing the page
- **Missing notifications**: Check your filters and date range

### Sending Issues

**If you can't send messages**:
- Verify you have permission to send messages
- Check you're connected to the correct lab units
- Ensure message content meets length requirements
- Try sending a shorter test message

## Getting Help with Notifications

### Common Questions

**Q: How long are notifications kept?**
A: Notifications are retained for 90 days, after which they are automatically archived.

**Q: Can I recover deleted notifications?**
A: No, once notifications are marked as read and archived, they cannot be recovered.

**Q: Why am I not receiving task notifications?**
A: Check your lab unit assignments and notification preferences in your profile settings.

**Q: Can I export my notifications?**
A: Yes, use the export feature on the notifications page to download as PDF or CSV.

### Contact Support

For notification issues:
1. Note the specific problem you're experiencing
2. Include screenshots if possible
3. Mention your browser and device information
4. Contact your system administrator
