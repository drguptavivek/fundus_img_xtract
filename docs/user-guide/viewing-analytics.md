# Viewing Analytics

This guide explains how to access and interpret the analytics and reporting features of the Fundus Image Management System. Analytics provide valuable insights into grading patterns, system performance, and quality metrics.

## Accessing Analytics

### Analytics Dashboard

1. Log in to the system with appropriate permissions
2. Click on "Analytics" in the main menu
3. The analytics dashboard provides an overview of:
   - System statistics
   - Recent activity
   - Key performance indicators
   - Quick access to detailed reports

### Permission Requirements

Analytics access varies by role:
- **File Uploaders**: Basic upload statistics
- **Residents**: Personal grading statistics
- **Resident2**: Departmental grading metrics
- **Data Managers**: Full system analytics
- **Administrators**: Complete access to all reports

## System Overview

### Key Metrics

The system overview displays:
- **Total Images**: Number of images in the system
- **Graded Images**: Images that have completed grading
- **Pending Tasks**: Images awaiting grading
- **Active Users**: Currently active system users

### Activity Timeline

Visual representation of:
- Image uploads over time
- Grading completion rates
- User activity patterns
- System usage trends

## Upload Analytics

### Upload Statistics

Track image upload metrics:
- **Upload Volume**: Number of images uploaded per period
- **Upload Sources**: Breakdown by camera type and source
- **Upload Success Rate**: Percentage of successful uploads
- **Processing Time**: Average time from upload to availability

### Quality Metrics

Monitor upload quality:
- **Image Quality Distribution**: Quality scores of uploaded images
- **Rejection Reasons**: Common causes of upload failures
- **Duplicate Rate**: Percentage of duplicate uploads
- **Format Compliance**: Adherence to format requirements

### Viewing Upload Reports

1. Navigate to "Analytics" → "Upload Reports"
2. Select date range and filters
3. Choose report type:
   - Summary Overview
   - Detailed Breakdown
   - Trend Analysis
4. Click "Generate Report" to view results

## Grading Analytics

### Grading Performance

Monitor grading efficiency:
- **Grading Speed**: Average time per image
- **Completion Rates**: Percentage of graded images
- **Backlog Status**: Images awaiting grading
- **Grader Productivity**: Performance by individual graders

### Consensus Analysis

Review grading consensus:
- **Agreement Rates**: How often graders agree
- **Discrepancy Patterns**: Common areas of disagreement
- **Arbitration Frequency**: Cases requiring senior review
- **Consensus Distribution**: Final grade distributions

### Disease-Specific Metrics

Analyze by disease type:
- **Diabetic Retinopathy**: Grading patterns and severity distribution
- **Glaucoma**: Detection rates and grading consistency
- **AMD**: Age-related macular degeneration metrics
- **Cross-Disease**: Correlations between conditions

### Quality Assurance

Track grading quality:
- **Revision Rates**: Frequency of grade revisions
- **Time to Consensus**: Average time to reach final grade
- **Grader Consistency**: Individual grader consistency over time
- **Calibration Needs**: Areas requiring additional training

## User Performance Analytics

### Individual Statistics

For residents and resident2:
- **Images Graded**: Total number of images graded
- **Average Time**: Time spent per image
- **Consensus Rate**: How often grades match consensus
- **Revision History**: Pattern of grade revisions

### Team Performance

For departments and units:
- **Team Productivity**: Collective grading output
- **Workload Distribution**: Balance among team members
- **Collaboration Metrics**: Cross-review patterns
- **Training Needs**: Areas requiring additional support

## Reporting Features

### Standard Reports

Pre-built reports for common needs:
- **Monthly Summary**: Overview of system activity
- **Grading Report**: Detailed grading statistics
- **Quality Report**: Quality metrics and trends

### Custom Reports

Create tailored reports:
1. Click "Create Custom Report"
2. Select data parameters:
   - Date range
   - User or department
   - Disease type
   - Specific metrics
3. Choose visualization format:
   - Tables
   - Charts
   - Graphs
4. Save report configuration for future use

### Export Options

- **PDF**: For presentations and sharing
- **Excel**: For further analysis
- **CSV**: For data integration
- **Image**: PNG/JPG for inclusion in documents

## Troubleshooting Analytics

### Common Issues

**Reports Not Loading**
- Check your internet connection
- Clear browser cache
- Try a different browser
- Verify your permissions

**Incorrect Data**
- Verify selected filters
- Check date ranges
- Confirm data source
- Report persistent issues to administrator

**Performance Issues**
- Reduce date range for reports
- Close unnecessary browser tabs
- Try during off-peak hours
- Contact IT if problems persist
