      Instructions
      Database Restore Process
      1. Upload Backup File: Select a backup file (.sql, .sql.gz, or .zip format)
      2. Review Preview: Check the backup file contents and user information
      3. Confirm Restore: Click "Restore Database" after confirmation
      4. Complete Overwrite: All data including users will be replaced with backup content
      ⚠️ Important Notes
      • Complete Data Overwrite: All existing data will be replaced
      • User Accounts: Users from backup will be restored with working passwords
      • Cannot Be Undone: This is a destructive operation
      • Backup First: Always create a current backup before restoring
      Supported File Formats
      • .sql: Plain SQL dump files
      • .sql.gz: Gzipped SQL dump files (smaller size)
      • .zip: ZIP archives containing SQL files
      Tip: For large databases, consider using gzipped files (.sql.gz) to reduce upload time and storage requirements.
