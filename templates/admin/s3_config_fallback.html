What This Means
Local-First Policy

The system now follows a local-first storage policy:

  • Files are first saved to local storage
  • If S3 is configured, files are also uploaded to S3
  • If S3 upload fails, the local copy remains available
  • Uploads never fail due to S3 issues

This ensures data reliability and service continuity even when S3 is unavailable.
