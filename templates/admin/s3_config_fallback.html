Recommendation

Use "NEVER" (Fail Hard) for production environments where:

  • S3 reliability is high (e.g., AWS, Cloudflare R2)
  • Security is more important than availability
  • You want to be immediately notified of S3 issues

Use "ALWAYS" (Local Fallback) for:

  • Development/testing environments
  • Migrating from local to S3 storage
  • When service continuity is critical
