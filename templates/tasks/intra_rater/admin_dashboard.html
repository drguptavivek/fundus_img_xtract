How Intra-Rater Batch Creation Works

Use this workflow to re-assess images a grader has already seen, so you can measure intra-rater consistency.

  1. Pick a disease and hospital. These are mandatory. Once both are selected, eligible lab units and grader options become visible.
  2. Optional lab unit filter. Narrowing to a lab restricts the grader list to users mapped to that lab for the chosen disease.
  3. Grader eligibility guardrails. Only users who hold resident/resident2/arbitrator permissions for the disease within the hospital (and lab, if provided) are offered.
  4. Historical image selection. For each grader the service searches their prior grades, skipping images already pending and enforcing the cool-down window (global default or override).
  5. Abnormal-first ordering. The optional “Normal grade” value helps the selector prefer previously abnormal cases before filling with normal ones.
  6. Target distribution. The requested number of images per grader is allocated without duplication; each selection spawns an intra-rater task linked to the original grading task.
  7. Immediate feedback. After creation, the dashboard refreshes the batch list and aggregate counts so you can confirm totals without reloading.

All intra-rater tasks remain private to the assigned grader plus admins/data managers, and can be completed from the “My Intra-Rater Tasks” page.
